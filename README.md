# Rockstar Capital property links

QR code landing pages, one folder per property, served by GitHub Pages at
`https://rockstar-capital-management.github.io/<property>-links/`.
Once the links.rockstar-capital.com subdomain is set up, GitHub forwards these to `https://links.rockstar-capital.com/<property>-links/`.

| Property | Page |
|---|---|
| Lakeview at Westpark | `/lakeview-links/` (its own repo: lakeview-links) |
| Deerbrook Forest | `/deerbrook-forest-links/` |

Scan and button-tap counts: GoatCounter (rockstarcapital.goatcounter.com). Button tags are prefixed with the property name (for example `deerbrook-apply-now`).
